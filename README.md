# Python Projects

A collection of beginner-to-intermediate Python projects, built incrementally while learning core programming concepts — from basic logic and loops to file handling and persistent data storage.

## Projects

### 1. Calculator (`calculator.py`)
A basic command-line calculator supporting core arithmetic operations. First project in the series — focused on functions, user input, and conditional logic.

### 2. Number Guessing Game (`guessing_game.py`)
A simple interactive game where the user tries to guess a randomly generated number. Introduces loops, random number generation, and win/lose conditions.

### 3. Password Generator (`password_generator.py`)
Generates secure random passwords based on user-defined criteria (length, character types). Later updated to include a file-saving feature, so generated passwords can be stored and retrieved.

### 4. To-Do List App (`To-do-list.py`)
A menu-driven to-do list application with full CRUD functionality (add, view, complete, delete tasks). Uses JSON for persistent storage, so tasks are saved between sessions.

## What This Series Covers

Across these four projects, the following concepts are progressively introduced and reinforced:

- Variables, data types, and operators
- Conditional logic (`if`/`elif`/`else`)
- Loops (`while`, `for`)
- Functions and code reuse
- Lists and dictionaries
- User input handling and validation
- File I/O and JSON persistence
- Menu-driven program design

## Getting Started

### Requirements
- Python 3.x

### Running a Project
Each project is a standalone script. Run any of them directly:
```bash
python calculator.py
python guessing_game.py
python password_generator.py
python To-do-list.py
```
